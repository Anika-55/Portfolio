A modern, interactive, and fully responsive personal portfolio website built with Next.js and React.
This project showcases my skills, projects, and experience as a web developer, with smooth animations, 3D elements, and a clean UI.

Live-Link: https://portfolio-my-tau-ivory.vercel.app

✨ Features

⚡ Built with Next.js 16 and React 19

🎨 Modern UI styled with Tailwind CSS

🎥 Smooth animations using Framer Motion

🧩 Interactive 3D elements using React Three Fiber & Drei

🎬 Lottie animations support

📱 Fully responsive for all devices

🧹 Clean and scalable folder structure

🚀 Optimized for performance and SEO
